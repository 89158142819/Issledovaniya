# Поиск медицинских услуг

Одностраничный справочник по проекту номенклатуры медицинских услуг от 22.10.2026.

## Публикация через GitHub Pages

1. Загрузите `index.html` в корень репозитория (кнопка **Add file → Upload files**).
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. После публикации сайт будет доступен по адресу: https://89158142819.github.io/Issledovaniya/

Файл `index.html` — самостоятельная страница; дополнительные библиотеки и сервер не требуются.

> Источник данных — загруженный проект номенклатуры от 22.10.2026. Наличие проекта в справочнике не подтверждает вступление документа в силу.
